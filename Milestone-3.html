1. For Cal Enviro Screen datasets

Teams will be asked to summarize tract level environmental measures into county level measures and compare with asthma ED rates overall or by a specific strata. The first is to compare county asthma ED rates with a county CES measure to assess if there appears to be a correlation. The second is to compare asthma ED rates with county-level summaries for specific environmental measures to determine if those specific measures may be worth further investigation.

1.1 Recode common variable(s) to be combined with other datasets

# recode county to title format
ces_measure_clean <- ces_measure %>% 
  rename(county = california_county)
  
ces_scores_demog_clean <- ces_scores_demog %>% 
  mutate(county = str_remove(county, " County"))

1.2 Identify environmental measure(s) of interest and summarize into a county-level value

We chose 1) PM2.5 and 2) Drinking Water as the environmental measures.

ces_measure_recat <-  ces_measure_clean %>% 
  group_by(county) %>% 
  summarise(asthma_ed_visits = mean(asthma, na.rm = TRUE),
            pm25 = mean(pm2_5, na.rm = TRUE),
            drinking_water = mean(drinking_water, na.rm = TRUE))

1.3 Summarize CalEnviroScreen score into a county level variable

ces_scores_demog_recat <- ces_scores_demog_clean %>% 
  group_by(county) %>% 
  summarise(ces_score = median(ces_4_0_score, na.rm = TRUE))

NOTE: the methods for each summary variable (environmental measure and CalEnviroScreen score) should be different (i.e. if you calculate the mean for one, please use another method for the other). If you look at more than one environmental measure you can re-use summarization methods for this.

We used mean for environmental measures, and used median for CES score.

2. Asthma ED dataset

The asthma ED dataset from the California Department of Health and Human Services reports the number and age-adjusted rate of emergency department visits for asthma by county, year (2015–2020), and demographic strata (total population, child vs. adult, age groups, and race/ethnicity). To compare it with the county-level CalEnviroScreen measures, we recode county names to match the CES datasets, fix values that read in incorrectly, keep only the most recent year and county-level rows, select the demographic strata of interest, and pivot the data so there is one row per county. Counts and rates for some small counties are suppressed for privacy and appear as missing values.

2.1 Recode common variable(s) to be combined with other datasets

# recode county to title case and remove extra spaces so it matches the CES datasets
chhs_asthma_clean <- chhs_asthma %>% 
  mutate(county = str_to_title(str_trim(county)))

2.2 Recode values that are reading in incorrectly

chhs_asthma_clean <- chhs_asthma_clean %>% 
  mutate(number_of_ed_visits = parse_number(as.character(number_of_ed_visits)),
         strata_name = gsub("[^ -~]+", "-", strata_name, useBytes = TRUE),
         strata_name = if_else(strata == "Total population", "All ages", strata_name))

2.3 Subset to most recent year and county level data

chhs_asthma_recent <- chhs_asthma_clean %>% 
  filter(year == max(year),          # most recent year (2020)
         county != "California")     # remove the statewide total row

2.4 Select demographic strata of interest

We chose to compare the total population, children (0–17 years), and adults (18+ years).

chhs_asthma_strata <- chhs_asthma_recent %>% 
  filter(strata %in% c("Total population", "Child vs. adult")) %>% 
  mutate(strata_name = case_when(strata_name == "All ages" ~ "total",
                                 strata_name == "0-17 years" ~ "child",
                                 strata_name == "18+ years" ~ "adult")) %>% 
  select(county, strata_name, age_adjusted_ed_visit_rate)

2.5 Pivot table to only include one row per county

chhs_asthma_recat <- chhs_asthma_strata %>% 
  pivot_wider(names_from = strata_name,
              values_from = age_adjusted_ed_visit_rate,
              names_prefix = "asthma_rate_") %>% 
  mutate(child_adult_diff = asthma_rate_child - asthma_rate_adult,
         child_adult_ratio = asthma_rate_child / asthma_rate_adult)
